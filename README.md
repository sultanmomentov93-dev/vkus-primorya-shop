# Вкус Приморья — Telegram Mini App

Готовая стартовая реализация визуального магазина по согласованной структуре: главная, категории, каталог из 14 сортов, карточки товара, избранное, корзина, профиль и оформление заказа.

## Важно перед запуском
Это исходный проект Mini App. Он не опубликован в интернете и не подключён к Telegram автоматически. Чтобы покупатели могли открыть его внутри Telegram, его нужно разместить на HTTPS-хостинге и указать URL в настройках бота через BotFather.

## Запуск локально
1. Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env`.
4. Заполните `BOT_TOKEN` и `ADMIN_CHAT_ID` локально. Не отправляйте токен в чаты и не публикуйте `.env`.
5. Запустите `uvicorn main:app --host 0.0.0.0 --port 8000`.
6. Откройте `http://localhost:8000` для проверки интерфейса. Вне Telegram создание заказов по умолчанию заблокировано; для локального теста можно временно поставить `ALLOW_BROWSER_DEMO=true`, но не включайте это на публичном сервере.

## Подключение закрытой группы
1. Добавьте бота администратором в группу заказов (это уже сделано).
2. В Telegram откройте группу и отправьте `/chatid` — команда есть в ранее переданном bot.py. Либо получите ID группы другим доверенным способом.
3. Укажите ID группы как `ADMIN_CHAT_ID` в `.env` на сервере.
4. Убедитесь, что бот может отправлять сообщения в группу.

## Подключение Mini App
1. Разместите проект на сервере с HTTPS.
2. В @BotFather выберите бота, настройте Web App / Menu Button и укажите HTTPS URL.
3. Откройте Mini App из Telegram и проверьте тестовый заказ. Сервер проверяет подпись `initData` Telegram перед сохранением заказа.

## Что пока требует отдельной настройки/контента
- реальные фотографии саженцев и проверенные сортовые описания (пока стоят аккуратные графические заглушки и нейтральные описания без выдуманных характеристик);
- контакты магазина;
- статусы и управление заказами из админ-панели;
- тарифы и расчёт доставки: сейчас покупатель выбирает Почту России или СДЭК, а детали менеджер согласует вручную;
- платёжная интеграция: не добавлена, так как способ оплаты ещё не утверждён.

Существующие данные старой базы SQLite этим проектом автоматически не импортируются: перед переходом на новый backend старую базу нужно отдельно перенести, если в ней есть важные заказы.
